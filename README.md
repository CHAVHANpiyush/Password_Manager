🔐 Password Manager

A simple Password Management Application built using Python (Tkinter).
This app allows you to generate strong random passwords, save them securely, and search stored credentials easily.

⸻

🚀 Features
	•	Password Generator
Generates random, secure passwords with letters, numbers, and symbols. Automatically copies the password to clipboard.
	•	Save Credentials
Saves website, email/username, and password into a data.json file in structured JSON format.
	•	Search Functionality
Quickly search for stored credentials by entering the website name.
	•	User-Friendly Interface
Built using Tkinter with a clean and simple design.

⸻

🛠️ Technologies Used
	•	Python 3
	•	Tkinter (for GUI)
	•	JSON (for storing credentials)
	•	Pyperclip (for copying password to clipboard)
	•	Random (for password generation)
